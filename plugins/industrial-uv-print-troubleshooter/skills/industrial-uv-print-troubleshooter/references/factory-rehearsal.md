# 离线演练与现场验收

离线演练输出到新建的本地非 RIP 监听目录，使用独立副本，不改客户源文件。scripts/uv_rehearse.cjs 的使用须先核对当前许可与其实际软件依赖，不能在运行生产任务的应用中直接执行。

文件检查、模拟输出、菜单可见、真实 RIP、设备接收、实体喷印和首件验收是独立结果，分别记录输入输出哈希、软件版本、范围、未知项和当前观察依据。不能将本机回环接收器的成功推导为 PrintExp 或打印机已经接受任务。

现场验证依次核对：图稿物理尺寸及通道；匹配的 RIP、驱动与材料方案；当前设备、窗口和队列；扫描与模板贴合；产品数量和逐件图稿；单次打印授权；实体完成与质量。每次改变图稿、扫描、模板、装夹或材料后重新核实受影响步骤。

自动输出、生产热文件夹、网络发送、扫描和打印都属于可能触发生产的动作，不能借离线演练自动执行。以当前适配器的状态、证据、授权和一次性命令校验为准。
