# PrintExp 操作核实

每次接入都从实际安装的 EXE、窗口、配置、版本与当前状态建立证据。公开包不携带某台机器的安装路径、板卡地址、网卡状态或生产参数，其他站点的记录不能作为当前默认值。

1. 只读发现 PrintExp_X64.exe 的真实路径、产品和文件版本；目录联接与实际目标应核对为同一安装。语言资源和 DLL 存在仅说明文件存在，不能证明可操作或授权有效。
2. 读取当前唯一窗口，检查队列、模态与状态。菜单可见不代表输入成功，输入成功不代表产品或参数已经验收。桌面接口不可读时记录具体阻点，不反复试点。
3. 网络连接按当前实际板卡、专用网卡、厂商配置和现场授权核实，不套用历史 IP 或端口。应用进程存在、监听存在、RIP 接收和物理打印分别核实。
4. 图稿先检查物理尺寸、DPI、颜色与真正专色通道；再核实 RIP 的机型、喷头、墨水、通道顺序、材料方案和输出格式。PRN 扩展名不能证明兼容。
5. 导入前核对自动启动状态，导入后检查任务缩略图、尺寸和方案。按当前授权进入 visual-scan-compat.md、visual-selection-print.md 的扫描、验证与单次打印流程。
6. 首件按订单要求单独检查尺寸、外观、颜色、附着与固化，保留适用范围。软件完成提示不能代替实体质量验收。

跨权限输入受 Windows 支持的权限模型约束。接口失败时由用户通过正常方式处理启动和权限，不修改 EXE 清单、UAC 或设备联锁，也不绕过应用授权。故障细节按 diagnosis-flow.md 与 rip-and-file-checks.md 分流。
