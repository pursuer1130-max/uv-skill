# PrintExp 生产期间只读学习

2026-09-18，客户说明设备正在生产。本流程只读进程元数据、安装目录资源和日志；不恢复窗口、不抢焦点、不打开菜单、不向设备或软件发送命令。新代码是日志工具，不是新的打印控制器。早先单次扫描、框选、打印授权不延续到本次生产观察。

## 运行方法

```text
node scripts/uv_printexp_logs.cjs --root "<刚刚确认的 PrintExp 安装目录>"
```

脚本仅使用 Node 内置模块，默认每类最近 3 个文件、每个最多 2 MiB、合计最多 12 MiB；读取之间短暂让出执行时间。大文件读取首尾片段，不追赶不断增长的日志。读取共享中的文件发生变化时保留 `changedDuringRead` 标记；读取失败记录错误、不重试、不解锁文件。不会打开数据库、转储、套接字，也不会启动或注入应用。

可从 Node `require('./scripts/uv_printexp_logs.cjs')` 调用 `inventory(root)`、`collect(root, limits)`、`compare(first, second)`；限制不可超过代码上限。`compare` 只报告同一安装下文件增长或缩小，绝不据此发出完成、复位、取消、恢复或重打指令。只做单次观察；持续监测需要另行明确请求。
