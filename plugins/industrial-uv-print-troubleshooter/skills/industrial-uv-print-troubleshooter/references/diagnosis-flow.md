# Industrial UV Diagnosis Flow

Start with the smallest safe checks:

1. Confirm the exact symptom, affected colors, media, job file, RIP preset, pass count, and whether the fault appears on nozzle test.
2. If the nozzle test is bad, prioritize ink path, head condition, negative pressure, cap station, wiper, and carriage/head cable checks.
3. If the nozzle test is good but production print is bad, prioritize RIP settings, file channels, media profile, speed/pass count, curing, static, and head height.
4. If the fault appeared after maintenance, inspect the recently touched part first.
5. If the fault appeared after a file/profile change, compare against the last known good job.
