# 当前设备与高度依据

历史 height-safety / height-transition 软件锁和旧跨机器 device-review 路线已经退役。旧记录的存在、缺失、损坏或数值不同不能阻断当前动作；公开包不分发这些设备档案。

实际 Z 应从当前新鲜状态观察。扫描高度字段只能核对本次观察后是否改变，不能推导实际 Z、材料高度或净间隙。人工测高与当前授权只在同一未变化作业中复用，设备、材料、装夹或高度条件变化后重新核实。

EXE 与窗口身份、空闲状态、新鲜控件与图像、明确动作授权、一次性命令消费、模板/选择/产品验证绑定、Z 手动输入语义校验和原生设备联锁继续有效。状态未知、忙碌、控件禁用或参数变化时停止受影响动作；不改驱动、固件或设备联锁。
