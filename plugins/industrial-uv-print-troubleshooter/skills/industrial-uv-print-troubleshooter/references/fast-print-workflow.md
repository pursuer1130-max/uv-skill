# 制图到打印优先流程（2026-10-15）

本流程针对已授权的当前作业；维护插件不执行设备动作。先做一次只读完整性及授权检查，从当前源重新 Stage，禁止复用未知版本运行目录。复用同一未变化作业的已给授权和人工测高确认，不重复询问。不承诺设备速度或未知故障不存在。

1. 制图：优先使用已选本地图案。Photoshop 副本导出脚本默认至少 300 DPI，不重采样、不修改源图。改 DPI 只改物理尺寸解释，不增加清晰度；导入后必须按实物重新贴合。对现成 TIFF，先 `node scripts/uv_fast_preflight.cjs inspect --file <绝对路径>`。必要时用 `dpi-copy --file <源> --out <全新非监听目录/图.tif> --isolated-output-confirmed --refit-after-import`；不支持的 TIFF 走 Photoshop 导出，禁止盲改文件头。
2. 扫描：先观察当前区域勾选。区域按钮是切换，不是幂等设定；只变更与目标不同的项，关闭菜单后读回。用户要求 1–4 时选中 1–4、取消其他；不把该范围作为所有机器默认。只在未扫描、现场改变或图像确实不可辨认时重扫。曝光值按现场图像调节，禁止复制本案例数值为默认。
3. 建模：必须基于当前已经明亮且清晰的扫描图。先清除旧框选，再在实物轮廓内部画一个小矩形，核对位置后新建命名。扫描曝光/图像改变后，旧暗图模板不继续使用。
4. 贴图：文件名使用 Windows 原生绝对路径；prepare 已规范化斜杠。打开一次，等待相应命令结果。先自动贴合并看图；需要时选择图案，用角点等比缩放、内部拖动/旋转，确认边界落在产品内再保存。避免反复点无效缩小按钮。
5. 全作业预检：`capture-print-evidence` 现在返回全部 `loadedTemplates`。用其新鲜 result.json 运行 `node scripts/uv_fast_preflight.cjs templates --root <当前PrintExp根> --observation <result.json>`。**主界面验证会处理全部已加载模板，而非仅选中项**。逐个检查 Temp.json、识别特征、Model2 文件和模板 TIFF DPI。缺文件先修复；对于明确属于本作业的废弃草稿，保存备份后仅从当前任务列表移除，禁止删除客户源文件或清空其他模板。预检通过不代表视觉识别通过。
6. 验证打印：从主界面执行产品验证；数量必须非零、位置和数量符合当前图像。任何改图、重扫、改模板或选择变化均重新验证。已获本次打印授权后提交一次打印，跟踪 RIP、打印完成和最终空闲；结果未知时只查同一命令/任务，禁止自动重打。物理质量单独确认。

## 异步和故障短路

每步以返回的命令 ID 对应 `runs/<id>/result.json` 完成为准，不能把启动成功当操作成功。可在当前 Sky 环境调用 `scripts/uv_desktop_session.cjs` 的 dispatch，传入新鲜唯一窗口；它最多等待45秒，超时返回同 ID 待查且不重试。prepare 检测上一命令 started 未有 result 时拒绝覆盖。不要在助手运行时穿插会抢焦点的终端调用。

出现 `CreateEmptyImage error` / `LoadModel2 file not exist` / HALCON #5200 时先查全部已加载模板文件；不要无依据反复改扫描区域。出现 DPI 低于300先修图稿再重贴合。对话框路径错误先核对路径格式，不反复随便换图。工具栏被悬浮宠物遮挡导致布局哈希变化时先移开遮挡、重新观察，不关闭图像守卫。

局部验证后的编辑器可能缩小或出现“恢复窗口”。重新观察所属窗口和按钮，再恢复/调整可用窗口；不能沿用旧截图坐标。关闭编辑器只执行一次并检查实际弹窗，禁止循环 Alt+F4。任何不明结果先读取当前状态和日志，避免重复动作。
