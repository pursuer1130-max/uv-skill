# UV 打印生产问题库

## 分诊规则

先记录故障出现时间、覆盖哪些颜色/区域、是否随扫描方向改变、是否换材料/墨水/文件后出现。比较同一文件、同一方案、同一材料的已知合格样。每轮只改变一个变量，记录原值、试样和验收结果。正在碰撞、漏墨到电气部位或异常发热时，按该机停机规程处理并交设备人员检查。

以下是工程排查建议，不是针对本机已执行的维修。跨品牌资料只支持故障机理，不迁移其电压、负压、灯功率、清洗液、墨水配方、湿度范围或坐标正负号。

## 印前与任务

Photoshop 专色使用通道表示；屏幕显示效果不能证明 RIP 已识别白墨/光油。通道名称与文件格式必须与接收 RIP 约定一致。[Adobe：Print spot colors，2023-05-24](https://helpx.adobe.com/photoshop/using/printing-spot-colors.html)

| 编号 | 症状 | 可能原因 | 首个验证动作 |
|---|---|---|---|
| F01 | 尺寸不对 | 单位、DPI解释、RIP缩放 | 对照像素/DPI换算毫米及队列最终尺寸 |
| F02 | 圆变椭圆 | 非等比缩放、运动比例 | 先量文件长宽，再比较实物两个方向 |
| F03 | 细字锯齿 | 素材像素不足、重复缩放 | 查原图实际尺寸，比较未重采样文件 |
| F04 | 白墨完全不出 | 专色丢失、RIP映射、白通道缺墨 | 分开查看RIP白版和喷嘴测试结果 |
| F05 | 白边外露 | 白版扩缩、套色偏差 | 比较分色边缘与机械套准，逐项排除 |
| F06 | 透明处被填白 | 背景层、透明蒙版、自动白版方式 | 检查透明区对应的白版数据 |
| F07 | 背印文字反向 | 观看面与镜像重复设置 | 标注正面/背面，只在一个环节镜像 |
| F08 | 发灰或颜色偏移 | 缺色、源配置、重复色彩转换 | 先查喷嘴，再查输入配置与RIP方案 |
| F09 | 重打颜色不同 | profile/墨批/模式/材料变化 | 对照上次任务哈希与完整方案记录 |
| F10 | TIFF导入失败 | 入口只收机器栅格任务、格式限制 | 查过滤器及集成RIP，生成兼容任务 |
| F11 | PRN打不开或数据异常 | 机型、通道顺序、模式不兼容 | 由本机匹配RIP重新生成小任务 |
| F12 | 重复打印、份数不对 | 连晒与份数相乘、重复入队 | 核对单任务份数、阵列及队列数量 |

F10–F12 是软件交接检查建议；本地 PrintExp 的实际任务导入尚待验证，不能以语言标签或 DLL 存在替代。

## 喷墨与图像缺陷

Mimaki 的条纹排查包括喷嘴、介质进给和打印方向等因素；其中涉及溶剂机加热的建议不适用于任意 UV 设备。[Mimaki：RIPCenter 条纹排查，2020 版资料](https://mimaki.com/archives/034/202009/47265001EE8_RIPCenter_EN_88898_1.pdf)

| 编号 | 症状 | 可能原因 | 首个验证动作 |
|---|---|---|---|
| I01 | 固定白线/断线 | 缺孔、供墨异常 | 保存喷嘴图，确认缺孔是否固定 |
| I02 | 周期性深浅条带 | 步进、拼接、羽化 | 测条带间距，对照喷幅和进给周期 |
| I03 | 双向重影 | 双向偏移、头距变化 | 相同条件对比单向和双向试样 |
| I04 | 颜色边缘错位 | 喷头间距、套色 | 用独立色线图确认方向和偏移量 |
| I05 | 打一会儿开始断墨 | 供墨受限、气泡、温度变化 | 比较开机与故障时喷嘴图、供墨状态 |
| I06 | 大实地不均 | 缺孔、墨量、材料润湿 | 比较小色块与大面积，同步记录喷嘴 |
| I07 | 随机墨滴 | 底板污染、供墨状态异常 | 检查滴落位置与底板状态，交维护人员 |
| I08 | 点偏斜、卫星点 | 喷孔污染、静电、头距 | 从材料静电和喷嘴基线分流排查 |

白墨沉降可能造成密度和供墨问题。循环、混匀和清洁必须按本机墨路设计与墨水要求执行，不能把另一品牌的菜单路径照搬。[Roland：White ink quality or density issues](https://support.rolanddg.com/hc/en-us/articles/21927053833369-White-ink-quality-or-density-issues)

| 编号 | 症状 | 可能原因 | 首个验证动作 |
|---|---|---|---|
| W01 | 白墨逐渐变淡 | 沉降、供墨、白版浓度 | 对照白版与不同时间的白色色块 |
| W02 | 隔夜白墨缺孔 | 停机维护、沉降、封帽 | 查停机记录及厂家规定的循环状态 |
| W03 | 白底遮盖不够 | 墨量/层数、基材颜色、缺孔 | 比较同墨层在黑/透明基材上的试片 |
| W04 | 白彩之间起边 | 层间相容性、固化、套色 | 分开评估白层附着与彩层附着 |

## 静电、材料与机械

静电可使落点偏移、吸附墨雾并引起滴墨。先核对材料与环境，再由具备资质人员检查接地；资料中的湿度值只适用于它标明的机型。[Mimaki：Why do I need to remove Static?，JFX200-2513](https://india.mimaki.com/support/faq/operation/entry-58767.html)

UV 反射与较大头距会增加喷头表面固化/墨雾风险；平整治具和反射控制需遵循设备允许范围。[Roland BF-16：Checking Before Printing](https://downloadcenter.rolanddg.com/contents/manuals/BF-16_USE_EN/ohp1710138704182.html)

| 编号 | 症状 | 可能原因 | 首个验证动作 |
|---|---|---|---|
| M01 | 图像周围毛边墨雾 | 静电、头距、材料形状 | 比较除静电处理前后同一试片 |
| M02 | 镜面材料后频繁堵头 | 反射固化 | 停用未批准反光材料，核对厂家方案 |
| M03 | 擦头、刮痕 | 翘曲、最高点未测、治具松动 | 停止输出并核对整件最高点和固定 |
| M04 | 局部模糊 | 高差或材料起伏 | 绘制表面高度差，检查治具支撑 |
| M05 | 整幅位置偏移 | 原点、偏移量、治具位置 | 对照任务位置与实际基准，先不复位 |
| M06 | 越打越歪 | 进给、固定、收放卷张力 | 检查材料路径与左右受力 |
| M07 | 尺寸随长度累积误差 | 运动比例、打滑、材料伸缩 | 测不同长度误差，区分比例与常量 |
| M08 | 圆柱接缝错位 | 直径/周长、夹持打滑 | 核对实测周长、图宽和夹持重复性 |
| M09 | 吸附不足 | 漏气、分区、板材平整度 | 核对有效吸附区和漏气位置 |
| M10 | 限位/伺服报警 | 机械阻力、传感器、线路 | 保存首条报警和位置，交设备维修 |

M05–M10 属于工程分诊框架，需机器厂家资料进一步定位，不能从 PrintExp 提示直接生成伺服/齿轮比改值。

## 固化、附着力与光油

灯强度变化可能同时影响固化和表面均匀性，因此“加灯”不是所有质量问题的共同答案。[Roland VersaWorks：UV Lamp Adjustment](https://files.rolanddga.com/Files/VersaWorks_6/topic/tUVLampAdjustment.html)

墨水、材料和预处理需要组合验证。附着力测试应依据订单用途和约定方法；表面不粘手并不证明耐刮或耐洗合格。[Inkcups：UV Ink Adhesion Improvement Components，2021-08-31](https://www.inkcups.com/blog/uv-ink-adhesion-improvement-components/)

底涂应按材料选择并涂于基材。Fujifilm Uvijet ZE 的用途不能推导成往任意喷墨墨水中添加助剂。[Fujifilm：Uvijet ZE Adhesion Promoters](https://www.fujifilm.com/ca/en/business/graphics-printing/large-format-printing/inks/adhesion-promoters)

| 编号 | 症状 | 可能原因 | 首个验证动作 |
|---|---|---|---|
| C01 | 墨面发粘/蹭花 | 固化不足、厚墨层、灯异常 | 隔离试样，核对灯使能、模式、墨层 |
| C02 | 一刮就掉 | 材料污染、墨材不匹配、固化 | 同批材料做清洁/批准底涂对照 |
| C03 | 弯曲后裂纹 | 墨层柔性与基材不匹配 | 按成品弯曲条件对比薄厚墨层 |
| C04 | 切边崩墨 | 边缘附着、应力、后加工 | 比较加工前后，检查切削条件 |
| C05 | 表面干但内部异常 | 层厚与固化不匹配 | 分层试片，核对墨水厂家固化条件 |
| C06 | 塑料发黄或翘曲 | 材料耐热、曝光累计 | 测材料温升并核对可用工艺窗口 |
| C07 | 光油颗粒 | 尘埃、静电、表面污染 | 比较打印前清洁和环境落尘 |
| C08 | 光油亮哑不均 | 固化时序、表面、模式 | 固定材料和墨量，对照批准方案 |
| C09 | 光油与彩层脱离 | 层间附着、污染、时序 | 分别评估各层并记录间隔时间 |
| C10 | 浮雕高度不稳 | 层数、墨量、位置重复性 | 测多点高度并记录叠印次数 |
| C11 | 耐洗/耐候不达标 | 应用环境超出墨材组合能力 | 按订单条件做有记录的耐久试验 |

光油表面可能受灯光发射方式及打印顺序影响，具体工艺属于对应设备和墨水。[Roland：Surface Finishing](https://downloadcenter.rolanddg.com/contents/manuals/UV-Guide_USE_EN_R1/qhq1604992790234.html) 光油颗粒可来自打印前或打印中的落尘。[Roland：UV Gloss specks，2020-05-13](https://www.rolanddga.com/support/products/print-printcut/soljet-ej-640-large-format-inkjet-printer/article?articleId=how-do-i-reduce-the-specks-or-imperfections-in-the-uv-gloss-layer-enduser&pm=EJ-640)

## 软件与通信

| 编号 | 症状 | 可能原因 | 首个验证动作 |
|---|---|---|---|
| S01 | 能看到窗口但点击无效 | 完整性差异、遮挡、模态、坐标 | 观察一次输入结果，核对进程完整性 |
| S02 | 未连接、无法打印 | 物理链路、地址、驱动、板卡供电 | 用只读探测区分网卡Down与端口不可达 |
| S03 | 模块缺失/授权提示 | 缺文件、授权或版本不匹配 | 核对具体报错和模块，保持原始授权 |
| S04 | 打印中断/速度异常 | 通信、RIP供数、磁盘、任务复杂度 | 对齐软件/系统日志时间和中断位置 |
| S05 | 软件闪退 | 依赖、配置损坏、文件触发 | 保存错误事件，对比已知有效小任务 |

## UV DTF 与交付

UV DTF Mini 厂商资料提到走膜张力、覆膜压力、适合的加热条件和图形位置对转印的影响。不同 A/B 膜系统的结构与冷热工艺不相同，先识别耗材说明；不照搬该文的抽墨量和维护步骤。[Procolored：FAQs about UV DTF Printer Maintenance，2024-07-19](https://www.procolored.com/blogs/news/faqs-about-uv-dtf-printer-maintenance)

| 编号 | 症状 | 可能原因 | 首个验证动作 |
|---|---|---|---|
| D01 | 膜起皱/走偏 | 走膜路径、左右张力/压力 | 对照本机穿膜图和耗材方向 |
| D02 | 转印不完整 | 膜配对、覆膜条件、固化 | 用同一图做小片对照并记录剥离表现 |
| D03 | 边角翘起 | 表面污染、适配性、贴合 | 对照清洁基材并检查使用条件 |
| D04 | 覆膜气泡/银纹 | 污染、贴合压力、膜平整度 | 比较未打印膜与打印膜的覆膜结果 |
| D05 | 图案碎裂留在膜上 | 固化、层间结合、转移条件 | 分段检查打印后、覆膜后、剥离后 |
| Q01 | 批次无法追溯 | 文件/方案/耗材记录缺失 | 绑定订单、文件哈希、墨批和材料批 |
| Q02 | 首件好而批量漂移 | 环境、喷嘴、耗材/位置变化 | 固定频率留样并记录变化时点 |
| Q03 | 包装后压痕或粘连 | 固化/后处理不足、堆叠条件 | 小批模拟实际包装和运输环境 |

Q01–Q03 为建议的质量流程，验收阈值需订单或厂内标准，不能由搜索结果替客户定义。

## 知识更新与资料取舍

新增案例保存：机型、喷头/墨水、版本、症状、发生条件、证据路径、假设、实施动作、结果、复发情况。未试验的原因保持“待验证”。应优先新增会改变诊断决策的证据，避免把搜索摘要全部塞进 SKILL.md。

本次未采用论坛帖作为技术结论。搜索到的 Fujifilm conventional UV 丝网墨添加剂指南不适合作为 UV 喷墨加料操作依据；部分厂商页面/PDF抓取失败，未据此声称读完。现有 59 项条目覆盖主要生产环节，但未知错误码、新墨水与厂家定制模块仍需持续补充。
