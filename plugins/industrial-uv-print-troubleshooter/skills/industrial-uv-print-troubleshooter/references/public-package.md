# GitHub 发布范围

本发布副本保留 UV 制版、Photoshop、PrintExp 扫描、建模、贴图、验证与单次授权打印的通用流程和适配器。原 U 盘维护源不变。

本机许可证、签名私钥、设备绑定信息、客户图稿、订单、截图、原始日志、历史动作授权、site-config 和历史知识记录不随仓库分发。RIIN 驱动、ICC/曲线、DPF 和其他厂商素材也不包含；需要时向有权分发的厂家获取与当前设备匹配的文件。

历史现场结果不能证明其他设备已经通过验证。每台设备均须重新发现软件与窗口、核对实际状态、许可和当前动作授权。扫描高度字段不能替代实际 Z、材料高度或净间隙。

源代码原有 Proprietary 声明保留。公开可见不代表授予开源许可，运行所需签名许可证另行提供。默认启动只校验文件，不连接打印机或启动扫描。
