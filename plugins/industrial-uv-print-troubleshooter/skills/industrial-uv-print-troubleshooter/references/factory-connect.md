# 新电脑接入

从实际选定的维护源完成 LoadCheck 与本机许可检查；使用 node scripts/uv_connect.cjs --root <本地非监听输出目录> 做只读接入预检。checks_complete_not_connected 表示检查完成，不是软件、相机或打印机已经连接。

软件路径、当前版本、设备状态和真实窗口在新电脑重新发现。默认接管现有窗口；需要启动时，先核实当前无生产任务以及对应启动授权。启动返回不明确时先重新枚举实际窗口，不重复启动。用户通过 Windows 正常机制处理提权，助手不绕过认证与系统策略。

RIIN 与 IKap 的现有窗口接入可查 scripts/uv_desktop_attach.cjs。PrintExp 使用其当前已审阅的适配器与动作守卫。相机软件可见不等于已完成采集、标定或定位验收。

设备许可优先选择 license/devices/<当前设备ID>.json，否则读取 license/license.json；选中的文件失效时不静默降级。没有许可时保留本地 license-request.json，由签发方另行提供匹配的签名文件。私钥不放在工厂电脑或公开仓库。

本包不分发 RIIN 驱动、ICC/曲线、DPF 或厂商软件。向有权分发的厂家获取与当前机型、板卡、喷头、墨水和通道顺序匹配的文件，不从文件名推导兼容性。先在未监听目录核对输出文件，再按当前作业授权做现场验证。
