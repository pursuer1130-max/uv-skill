# RIP and File Checks

Common checks:

- Confirm artwork size, resolution, color mode, embedded profile, and export format.
- Confirm spot white channel naming and overprint/transparency behavior.
- Compare ink limit, pass count, bidirectional setting, wave, feathering, and media profile against a known good preset.
- For white ink, check underbase/choke/spread settings and whether white is printed before, after, or sandwich mode.
- For adhesion or curing problems, compare lamp power, print speed, media pretreatment, and surface contamination.
